READY WHEN YOU ARE

三步，回到大屏

  1. 1

    导入配置地址

    在 TVBox 设置中粘贴上方链接，保存并选择对应站点。

  2. 2

    选择 Exo 播放器

    在播放器设置中选择 Exo。需要 Android 5.0 及以上，以及支持原生 Java Type 3 的 TVBox 分支。

  3. 3

    用哔哩哔哩扫码登录

    进入「Bilibili 影视」的扫码登录入口，用手机哔哩哔哩 App 扫描电视登录弹窗中的二维码并确认；没有弹窗时使用详情封面。成功后重新加载源配置或重启 TVBox，刷新收藏夹筛选。

◇账号登录在电视端完成，Cookie 保留在设备上。本网页无需登录，也不接收你的账号凭据。
